# 📊 Credit Risk Analytics Dashboard

An end-to-end machine learning deployment pipeline designed to calculate financial credit default probabilities and assess lending risk. This platform integrates a robust Python `scikit-learn` predictive engine with a highly polished, responsive glassmorphism web analytics interface.

🌐 **Live Demo:** [View Live App](https://credit-risk-model-bpvi.onrender.com)

## 🛠️ Core Tech Stack & Engineering Highlights

* **Machine Learning Pipeline:** `Scikit-Learn` (Decision Tree Classifier), `Pandas`, `NumPy`, and `Joblib` for automated serialization.
* **Web Deployment Framework:** `Flask` REST API backend for secure client-server communication.
* **Software Quality Assurance:** Full test coverage validation suite engineered via `Pytest`[cite: 4].
* **Modern UI/UX Interface:** Translucent dark-themed glassmorphism front-end styled via custom CSS3 backdrop filters and dynamic lighting engines[cite: 4].

---

## 📈 System Architecture & Workflows

1. **Data Pipeline & Processing:** Cleans and parses key borrower risk metrics (`Age`, `Income`, `LoanAmount`, and `CreditScore`) directly from underlying storage datasets (`credit_data.csv`)[cite: 4].
2. **Predictive Analytics:** Evaluates financial metrics across structured train-test boundaries to forecast credit defaults and minimize capital risk[cite: 4].
3. **Automated Testing Suite:** Integrated unit tests enforce runtime stability and validation logic[cite: 4, 5].
4. **Dynamic Risk-Glow Signaling:** The web application features real-time visual feedback—illuminating in **Neon Green (Low Risk)** for sound approvals and **Neon Red (High Risk)** for potential default flags[cite: 4].
